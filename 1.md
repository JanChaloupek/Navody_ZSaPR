# Instalace a nastavení Visual Studio Code
Průvodce krok za krokem

## Úvod
**Verze: 2025-12-01**

Visual Studio Code (VS Code) je populární vývojové prostředí, které podporuje různé programovací jazyky a je ideální pro práci s CircuitPythonem na platformě Pico:ed. Tento návod vás provede instalací a nastavením potřebných rozšíření, abyste mohli začít vyvíjet aplikace v CircuitPythonu, ukládat je na Pico:ed a spravovat svůj kód na GitHubu.

---

## Instalace Visual Studio Code
1. Navštivte [oficiální web VS Code](https://code.visualstudio.com/download).
2. Stáhněte a nainstalujte verzi pro váš operační systém (Windows, macOS, Linux).
3. Po instalaci spusťte VS Code.

![Stažení VS Code](images/vscode_download.png)

---

## Instalace potřebných rozšíření
Pro práci s CircuitPythonem a Pico:ed budete potřebovat následující rozšíření. Instalaci provedete ve VS Code otevřením sekce **Extensions** (ikona čtverců na levém panelu) a vyhledáním konkrétního rozšíření.

1. **Python**  
   - Podpora pro jazyk Python (zvýrazňování syntaxe, linting, ladění).  
   - Autor: Microsoft  

2. **CircuitPython v2**  
   - Rozšíření pro práci s CircuitPythonem, podporuje i Pico:ed.  
   - Autor: wmerkens  

3. **MagicPython**  
   - Lepší zvýrazňování syntaxe pro Python a CircuitPython.  
   - Autor: MagicStack Inc.  

4. **IntelliCode**  
   - Umělou inteligencí vylepšené dokončování kódu.  
   - Autor: Microsoft  

5. **Run on Save**  
   - Automatické spouštění skriptů při uložení souboru (užitečné pro nahrávání na Pico:ed).  
   - Autor: EmeraldWalk  

6. **PlantUML**  
   - Vytváření UML diagramů návrhu tříd.  
   - Autor: jebbs  

![Instalace rozšíření](images/vscode_extensions.png)

## Doporučená rozšíření
Časem možná sami objevíte další vhodná rozšíření.  

1. **Output Colorizer**  
   - Barevně zvýrazňuje logy.  
   - Autor: IBM  

2. **GitHub Pull Requests**  
   - Správa úložiště GitHubu (včetně pull requestů) přímo ve VS Code.  
   - Autor: GitHub  

3. **GitLens – Git supercharged**  
   - Edice *Community* je zdarma.  
   - Zobrazuje změny v kódu, rozdíly mezi verzemi a další funkce.  
   - Autor: GitKraken

## Vytvoření pracovního adresáře
Zdrojové texty musíte umístit do vhodného adresáře na disku (pracovní adresář), kde budete projekt editovat (např. v Dokumentech, na ploše, na OneDrive).  

1. Založte adresář, např. **joyCarProjekt**.  
2. Stáhněte archiv:  
   [vsc_init_circuitPythonProject-main.zip](https://github.com/JanChaloupek/vsc_init_circuitPythonProject/archive/refs/heads/main.zip)  
3. Archiv obsahuje složky `.vscode`, `lib` a `lib_vsc_only`. Nakopírujte je do pracovního adresáře.  
4. Součástí je i soubor `.gitignore`. Pokud nemáte vlastní, použijte tento.
